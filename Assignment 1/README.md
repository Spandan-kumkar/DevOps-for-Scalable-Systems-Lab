# Assignment 1: Git Basics and Version Control

## Aim
To create a GitHub repository for the Student Task Manager Web Application and demonstrate basic Git version control operations.

## Objectives
- Create and clone a GitHub repository.
- Track and commit application files.
- Push and pull changes between local and remote repositories.
- Create and switch branches.
- Merge feature branches into the main branch.
- Verify repository history.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- Node.js

## Git Operations Performed
1. Created the GitHub repository.
2. Cloned the repository to the local system.
3. Added and committed the application files.
4. Pushed the source code to GitHub.
5. Created a `feature-ui` branch.
6. Modified the application on the feature branch.
7. Committed and merged the changes into `main`.
8. Pulled the latest changes and verified the commit history.

## Outcome
Successfully demonstrated basic Git and GitHub version control operations using the Student Task Manager Web Application.
